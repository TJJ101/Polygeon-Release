# POLYGEON
Step into the Polygeon, an action dungeon-crawler that will have you being swarmed by enemies in the dungeon. 
Fight through hordes of enemies in typical hack and slash fashion or keep distance from enemies and shoot them down while kiting. 
You possess the ability to swap your playstyle at your own will, but this comes with a caveat... the enemies will swap weapons too, equipping a weapon of opposite type from the player!

## CONTROLS
### IN-GAME CONTROLS
    **Movement:**              
        - W Key                 |           *Move Up*
        - A Key                 |           *Move Left*
        - S Key                 |           *Move Down*
        - D Key                 |           *Move Right*
    
    **Attack:**
        - Move Mouse            |           *Aim*
        - Left Mouse Button     |           *Attack*

    **Special**
        - E Key                 |           *Polymorph*
        > Polymorph will switch player's playstyle between *Hack & Slash* and *Run & Gun* while enemies will be polymorphed to be the opposite.
    
    **Others:**
        - ESC Key               |           *Pause Game*

### MAP EDITOR CONTROLS
    **UI:**
        - Left Mouse Click     |           *Press button/select tile in tile painter (if mouse is on top)
        - Left Mouse Down      |           *Move tile painter window (if mouse is on top of it)

    **Non-UI:**
        - Left Mouse Click     |           *Paint at cursor*
        - Left Mouse Down      |           *Paint at cursor*
        - Mouse Scroll         |           *Zoom in/out*
        - Middle Mouse Down    |           *Move around*

    **Others:**
        - 1-5 Keys             |           *Change between sorting layers*
        - F Key                |           *Fill with current tile (cannot delete)*
        - 0 Key                |           *Fill with empty tile (Delete fill)*
        - R Key                |           *Reset Camera to origin (starting pos)*
        - X Key                |           *Erase current sorting layer when you paint*
        - C Key                |           *Erase ALL sorting layers when you paint*
        - Tab Key              |           *Hide Tile painter window*
        - Left Ctrl Key        |           *Hide Grid Number*

### Note:
    Others is just for QOL, functionally you can get by just knowing the UI and Non-UI key
